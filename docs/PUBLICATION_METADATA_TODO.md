# Publication metadata update checklist

Update the following when the official SIGCITE 2026 rights-and-metadata notice arrives:

- [ ] DOI in `paper/main.tex`
- [ ] DOI in `CITATION.cff`
- [ ] ACM ISBN in `paper/main.tex`
- [ ] Conference dates in `paper/main.tex` and `CITATION.cff`
- [ ] Conference location in `paper/main.tex` and `CITATION.cff`
- [ ] Final page range in `CITATION.cff`
- [ ] Version-of-record URL in `README.md`
- [ ] Repository release tag and archived DOI, if deposited with Zenodo or another archive

After updating `paper/main.tex`, compile twice, confirm the conference-approved page count, inspect every rendered page, and update `paper/VALIDATION_REPORT.md`.
