# Repository contents

The public release contains every artifact promised in the paper:

- frozen evaluator prompt, separated from third-party assignment text;
- pre-analytic rubric-drift transcript;
- preflight and midpoint fidelity verification record;
- sample catalog with source links, source-file hints, and licenses;
- seeded randomized order;
- corrected de-identified faculty and LLM scores;
- correction log;
- reproducible agreement and threshold analysis;
- generated results;
- model and platform documentation;
- coded blank scoring workbook;
- camera-ready manuscript source and PDF.

The release excludes assignment files whose licenses restrict redistribution, author-to-code linkage information, identifiable completed workbooks, private correspondence, credentials, and institutional records.
